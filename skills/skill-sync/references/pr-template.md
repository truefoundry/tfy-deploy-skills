# PR Body Template

The runtime fills this template per run. Variables are bash-interpolated by `run-sync.sh` and written to a file passed to `gh pr create --body-file`.

## How sections behave when empty

- If `TIER1_COUNT == 0`: render "_None — repo already agrees with the OpenAPI/docs for this batch._"
- If `TIER2_COUNT == 0`: render "_None._"
- If `TIER3_COUNT == 0`: render "_None._"
- If all three are zero: the runtime skips PR creation entirely and exits with a "no drift" log line. No empty PRs.

## Title format

`chore(skills): manual sync — ${SYNC_DATE_UTC}`

skill-sync is manual-only — there is no scheduled or "auto" variant. The date suffix makes the branch name (`skill-sync/YYYY-MM-DD`) deterministic per UTC day, so two manual runs on the same day update the same PR.
